# Agent: Strategist Agent

**ID**: `agent:Strategist`  
**Тип**: Strategic Agent (L3)  
**Роль**: Принимает решения на основе insights Analyst Agent

## Описание
Превращает аналитику в рекомендации и сценарии. Работает в режиме human-in-the-loop.

## Основные задачи (MVP)

1. Рекомендации по цене и промо
2. Сценарии риска ("что если")
3. Маржинальный калькулятор решений
4. Стратегия переговоров с поставщиком
5. Приоритизация действий

## Инструменты

- Scenario modeling
- What-if analysis
- LLM reasoning (Claude / GPT-4o)
- Шаблоны рекомендаций

## Вход / Выход

**Вход**:
- Insights от Analyst Agent (JSON)
- Профиль пользователя / корпоративная память (L5)

**Выход**:
- Рекомендация + обоснование (JSON + текст)
- Готовый draft действия для Executor Agent
- Approval gate (ожидание решения человека)

## "Вау"-эффект

> "Агент не просто показывает проблему, а предлагает: 'Рекомендую снизить цену на 7% у SKU-78432 — ожидаемый прирост маржи +1.8 п.п. и ROI 340% за 14 дней'"

## Связанные сущности

- `Margin`, `Forecast`, `Promo`, `Supplier`

## Статус
MVP — высокоприоритетный.
