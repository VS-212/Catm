# Agent: Executor Agent (Negotiator)

**ID**: `agent:Executor`  
**Тип**: Execution Agent (L4)  
**Роль**: Выполняет действия в системах

## Описание
Превращает одобренные решения в реальные действия: обновление Excel, отправка писем поставщикам, обновление цен в 1С.

## Основные задачи (MVP)

1. Генерация и отправка email поставщику (Negotiator)
2. Обновление цен / остатков в Excel
3. Подготовка данных для 1С
4. Создание промо-кампаний (draft)

## Инструменты

- Email (SMTP / Outlook / Gmail API)
- Excel automation (openpyxl / Office Scripts)
- 1С интеграция (REST / COM)
- Telegram / Slack уведомления

## Вход / Выход

**Вход**:
- Одобренная рекомендация от Strategist Agent + human approval

**Выход**:
- Выполненное действие + подтверждение
- Обновлённые данные в системах
- Лог в Governance (L5)

## "Вау"-эффект

> "Я нажал Approve — и через 40 секунд поставщик уже получил письмо с точным расчётом скидки и обоснованием. А в 1С и Excel всё обновилось автоматически."

## Связанные сущности

- `Supplier`, `SKU`, `Margin`, `Promo`

## Статус
MVP — критически важен для "вау"-эффекта.
