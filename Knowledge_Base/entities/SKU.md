# Entity: SKU

**ID**: `cat:SKU`  
**Тип**: Core Domain Entity  
**Слой по умолчанию**: L1 + L2

## Описание
Конкретная товарная позиция (Stock Keeping Unit) внутри категории.

## Атрибуты (MVP)

| Атрибут | Тип | Обязательный | Описание | Пример |
|---------|-----|--------------|----------|--------|
| `id` | UUID | Да | Уникальный идентификатор | `sku-uuid-78432` |
| `category_id` | UUID | Да | Ссылка на Category | `cat-uuid-001` |
| `name` | string | Да | Название товара | "Полотенце махровое 70x140 см" |
| `sku_code` | string | Да | Артикул / код в 1С | "TXT-78432" |
| `barcode` | string | Нет | Штрихкод | "4601234567890" |
| `price_retail` | float | Да | Розничная цена | 899.00 |
| `price_purchase` | float | Да | Закупочная цена | 412.50 |
| `margin` | float | Да | Маржа (%) | 35.2 |
| `stock_qty` | int | Да | Остаток на складах | 1240 |
| `sales_30d` | int | Да | Продажи за 30 дней | 387 |
| `abc_class` | enum | Да | A/B/C | "A" |
| `xyz_class` | enum | Да | X/Y/Z | "X" |
| `status` | enum | Да | Активен / Архив / Новый | "active" |
| `last_sale_date` | date | Нет | Дата последней продажи | 2026-08-12 |
| `supplier_id` | UUID | Да | Основной поставщик | `sup-uuid-003` |
| `non_food_attributes` | object | Нет | Специфические атрибуты non-food | `{color: "белый", size: "70x140"}` |

## Слои существования

| Слой | Представление | Операции |
|------|---------------|----------|
| L1 | Бизнес-правила (минимальная маржа, ассортимент) | Включение/исключение из матрицы |
| L2 | Аналитика (drift, OOS, elasticity) | Мониторинг, прогноз |
| L3 | Стратегические решения | Ценообразование, промо |
| L4 | Исполнение | Обновление цен/остатков в 1С |
| L5 | Память | История изменений SKU |

## Связанные сущности

- `Category` (N:1)
- `Supplier` (N:1)
- `Promo` (1:N)
- `Margin` (1:1)
- `Forecast` (1:1)

## Примеры агентов

- Inventory Watchdog (L2)
- Pricing Agent (L3)
- Executor Agent (L4)

## Статус
MVP — определена. Требуется детализация `non_food_attributes` для разных подтипов (fashion, cosmetics, DIY).
