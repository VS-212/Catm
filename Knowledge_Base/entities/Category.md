# Entity: Category

**ID**: `cat:Category`  
**Тип**: Core Domain Entity  
**Слой по умолчанию**: L1 (Business) + L2 (Analytical)

## Описание
Группа товаров с общими характеристиками, ценообразованием, поставщиками и стратегией. Основная единица категоризации в Catman.

## Атрибуты (MVP)

| Атрибут | Тип | Обязательный | Описание | Пример |
|---------|-----|--------------|----------|--------|
| `id` | UUID | Да | Уникальный идентификатор | `cat-uuid-001` |
| `name` | string | Да | Название категории | "Домашний текстиль" |
| `parent_id` | UUID / null | Нет | Родительская категория | `cat-uuid-000` |
| `level` | int | Да | Уровень иерархии (1-4) | 2 |
| `sku_count` | int | Да | Количество SKU | 1240 |
| `avg_margin` | float | Да | Средняя маржа (%) | 32.4 |
| `abc_class` | enum | Да | ABC-анализ | "A" |
| `xyz_class` | enum | Да | XYZ-анализ | "X" |
| `seasonality` | boolean | Нет | Сезонная категория | true |
| `non_food_subtype` | enum | Да | non-food подтип | "textile", "cosmetics", "diy", "fashion" |
| `last_updated` | datetime | Да | Последнее обновление | 2026-08-14T10:00:00Z |

## Слои существования

| Слой | Как представлена | Ключевые операции |
|------|------------------|-------------------|
| **L1 Business** | Бизнес-правила, ассортиментная матрица | Определение стратегии категории |
| **L2 Analytical** | ABC-XYZ, маржинальность, drift | Анализ продаж, прогноз |
| **L3 Strategic** | Рекомендации по ассортименту | Решение о расширении/сужении |
| **L4 Execution** | Обновление в 1С / Excel | Применение изменений |
| **L5 Governance** | История решений по категории | Корпоративная память |

## Связанные сущности

- `SKU` (1:N) — товары в категории
- `Supplier` (M:N) — поставщики категории
- `Promo` (1:N)
- `Forecast` (1:1)
- `Margin` (1:N)

## Примеры агентов, работающих с Category

- Analyst Agent (L2)
- Strategist Agent (L3)
- Domain Rules Agent (L1)

## Источники данных

- Excel-таблицы Catman
- 1С (справочники номенклатуры)
- POS-данные
- Маркетплейсы (WB, Ozon)

## Статус
MVP — определена. Требуется расширение атрибутов для конкретных non-food подкатегорий.
