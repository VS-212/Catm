# Entity: Supplier

**ID**: `cat:Supplier`  
**Тип**: Core Domain Entity  
**Слой**: L1 + L4 + L5

## Описание
Поставщик товаров категории. Ключевой партнёр в переговорах по цене, условиям, промо.

## Атрибуты (MVP)

| Атрибут | Тип | Обязательный | Описание | Пример |
|---------|-----|--------------|----------|--------|
| `id` | UUID | Да | Уникальный идентификатор | `sup-uuid-003` |
| `name` | string | Да | Название компании | "ТекстильПром" |
| `inn` | string | Да | ИНН | "7701234567" |
| `contact_email` | string | Да | Email для переговоров | `sales@textileprom.ru` |
| `contact_phone` | string | Нет | Телефон | "+7 495 123-45-67" |
| `payment_terms` | string | Да | Условия оплаты | "30 дней" |
| `avg_margin` | float | Да | Средняя маржа по поставщику | 28.5 |
| `reliability_score` | float | Да | Оценка надёжности (0-100) | 87 |
| `categories` | array[UUID] | Да | Категории, которые поставляет | `["cat-uuid-001"]` |
| `last_negotiation_date` | date | Нет | Дата последних переговоров | 2026-07-15 |
| `xray_data` | object | Нет | Данные "X-ray поставщика" | `{avg_delay: 4, quality_issues: 2}` |

## Слои существования

| Слой | Представление | Операции |
|------|---------------|----------|
| L1 | Бизнес-правила (минимальные условия) | Стратегия работы с поставщиком |
| L4 | Исполнение | Отправка писем, согласования |
| L5 | Память | История переговоров, корпоративная память |

## Связанные сущности

- `SKU` (1:N)
- `Category` (M:N)
- `Promo` (M:N)
- `Margin` (1:N)
