# White Spots — Белые пятна Knowledge Base

## Критические (MVP — закрыть в первую очередь)

### 1. Конкретные атрибуты non-food подтипов
- **Проблема**: Различия между fashion, cosmetics, DIY, home textiles не детализированы.
- **Что нужно**: Расширить `non_food_attributes` в SKU и Category.
- **Приоритет**: ★★★★★

### 2. Интеграция с 1С (точные протоколы)
- **Проблема**: REST vs COM vs OData vs прямой доступ к базе.
- **Что нужно**: Конкретные примеры запросов и схемы данных.
- **Приоритет**: ★★★★★

### 3. Точные KPI и метрики успеха
- **Проблема**: Отсутствуют бенчмарки (маржа +1–3 п.п., снижение потерь 15–25% и т.д.).
- **Что нужно**: Реальные цифры из кейсов + формулы расчёта ROI.
- **Приоритет**: ★★★★☆

### 4. Профиль пользователя и корпоративная память
- **Проблема**: Отсутствует детальная модель `UserProfile` и `CorporateMemory`.
- **Что нужно**: Атрибуты + механизмы обновления (Hermes-style).
- **Приоритет**: ★★★★☆

### 5. Multi-agent orchestration framework
- **Проблема**: Не выбрана финальная технология (n8n + LangGraph vs CrewAI vs собственный).
- **Что нужно**: Сравнительный анализ + рекомендация.
- **Приоритет**: ★★★★☆

- Конкурентная разведка (внешние сигналы)
